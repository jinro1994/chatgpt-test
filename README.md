# 宝塚 Data Lab

別チャットで作成した宝塚歌劇団の基礎コーパスを、GitHub Pages 用の研究ダッシュボードとして再構成したものです。

## 現在の収録

- 初期・証拠ベース人事シグナル指標
- 2027年カレンダー商品階層
- 2026年新人公演主要配役
- メディア個人化・編集同席データ
- 人事イベント（発表日 / 発効日を分離）
- キャトルレーヴ商品SKUスナップショット
- 分析指標（CDS / ERS / SCS / MIS / NGS / EPN / PTS）
- 出典レイヤー

## 原則

事実、公式商品・メディア観測、分析・予測を混在させません。
初期スコアは劇団の公式序列ではなく、コーパス作成時に確認できた公開証拠の密度を比較するための研究用指標です。
